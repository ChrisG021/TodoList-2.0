# Todo list - projeto de gerenciamento de tarefas 📋
Este é um projeto simples de uma aplicação de lista de tarefas (To-Do List) desenvolvida utilizando Java com Spring Boot. O objetivo é gerenciar tarefas com operações básicas como adicionar, listar, atualizar e excluir tarefas.

## Tecnologias Utilizadas 🚀

- **Java 21**
- **Spring Boot**
- **Spring Data JPA** (para persistência de dados)
- **H2 Database** (banco de dados em memória, pode ser substituído por outros)
- **Maven** (gerenciador de dependências)

## Funcionalidades 💻

- **Cadastrar uma nova tarefa**: Adiciona uma nova tarefa à lista.
- **Listar tarefas**: Exibe todas as tarefas cadastradas.
- **Atualizar tarefa**: Permite editar uma tarefa existente.
- **Excluir tarefa**: Remove uma tarefa da lista.
